# DMP Demand Planning — Analytics Dashboard

Standalone, static build of the Central team analytics dashboard from the
DMP Demand Planning prototype. It runs entirely in the browser from a bundled
data snapshot (`js/state-snapshot.js`) — no server is needed — and is meant to
be served with GitHub Pages.

The dashboard is the only page in this build: every in-app link stays on the
dashboard, and the role is fixed to the Central team.
